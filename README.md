# 凹凸宇宙桌面收听

仅供账号本人使用的桌面网页客户端。它通过服务端代理连接凹凸宇宙官方 API，让无法安装安卓模拟器的电脑仍可完成短信登录、读取会员节目和在线播放。

## 已实现

- 官方手机号短信验证码登录
- 会员状态校验、完整频道与节目列表
- 节目搜索、频道详情和单集详情
- 同源音频代理、官方媒体签名与 Range 拖动播放
- 播放速度、音量、前后跳转
- 仅保存在当前浏览器中的播放历史和续播进度
- 登录令牌加密存入 HttpOnly Cookie；浏览器脚本不可读取
- 私有部署、安全响应头和非开放式媒体代理

## 本地启动

```powershell
npm run dev
```

打开 `http://localhost:3000`。生产环境必须设置 `.env.example` 中的两个安全值；不要把真实值提交到版本库。

## 使用边界

本项目不下载节目、不绕过会员或专辑购买权限。会员节目仍由官方账号状态决定；单独付费专辑会继续要求官方 App 中的有效购买状态。上游接口属于第三方服务，若官方升级协议，客户端可能需要同步更新。
